PART 1: PROJECT OVERVIEW
1.1 What We Are Building
A modern, fast, client-side travel agency website for HTG Travels, based in Sialkot, Punjab, Pakistan. The website serves as a digital storefront and WhatsApp-first inquiry funnel for:

Domestic & international flight ticketing

Tourist & business visa consultation

Umrah & Hajj packages

Travel insurance

Hotel bookings

Corporate & group travel

The website has no backend, no database, no live API. Every inquiry is routed to WhatsApp with a pre-filled message. This is intentional — it keeps the site fast, secure, and maintenance-free while giving customers a direct line to a human expert.

Cloudflare Pages Specifics
Because we are deploying to Cloudflare Pages as a client-side static site:

Use output: 'export' in next.config.js for full static generation.

All pages must be statically renderable (no server-side runtime dependencies).

WhatsApp links open in a new tab — no server call needed.

Contact form uses WhatsApp deep link instead of POST request.

Images are self-hosted in /public/images/ and optimized at build time.

Use next/image with unoptimized: true if using static export, or Cloudflare Images for optimization.

Cloudflare Pages automatically provides SSL, HTTP/3, and global CDN.

Enable Cloudflare Browser Insights for RUM (Real User Monitoring).
